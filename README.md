# Codex Limits Widget

[Скачать последнюю версию для Windows](https://github.com/tehnalive/codex-limits-widget/releases/latest)

Компактный виджет для квот Codex: кольца показывают остаток в пятичасовом и недельном окнах, а подписи — время до сброса. Виджет находится в системном трее, может закрепляться поверх окон и предупреждает, когда остаётся меньше 20%.

## Установка

1. Скачайте `Виджет лимитов.exe` со страницы [последнего релиза](https://github.com/tehnalive/codex-limits-widget/releases/latest).
2. Запустите EXE. .NET устанавливать не нужно.
3. Убедитесь, что Codex CLI или приложение Codex установлено и выполнен вход в аккаунт ChatGPT.

Приложение не подписано цифровым сертификатом, поэтому Windows SmartScreen может показать предупреждение. Проверяйте загруженный файл и исходный код этого репозитория.

## Возможности

- Пять часов и семь дней: остаток, цветной индикатор и обратный отсчёт до сброса.
- Полупрозрачная тёмная карточка с размытием фона, лёгким зерном и минималистичными иконками.
- Закрепление поверх окон, перемещение мышью и управление из системного трея.
- Одно уведомление за окно лимита при остатке ниже 20%.
- Настройки в `%LOCALAPPDATA%\CodexLimitsWidget\settings.json`.

Кнопка «−» скрывает карточку в трей. Меню значка в трее позволяет показать её, включить или выключить закрепление, приостановить обновления, отключить уведомления и выйти. Автозапуск Windows не включён.

## Данные и совместимость

Виджет читает только сведения об аккаунте и квотах через Codex app-server. Он не читает `auth.json`, историю чатов, файлы задач или содержимое запросов; не запускает генерации и не сохраняет токены, email или исходный идентификатор аккаунта. Опрос выполняется раз в минуту, пока карточка открыта, и раз в пять минут, когда она скрыта в трее.

Для получения квот нужен Codex CLI или приложение Codex для Windows с выполненным входом в ChatGPT. Используется интерфейс Codex app-server, который может измениться в будущей версии Codex. Обычные чаты на chatgpt.com не подключены. Расход квоты по проектам и задачам не показывается.

Размытие использует системный эффект Windows; при выключенной прозрачности или высокой контрастности виджет использует непрозрачный фон. Сборка предназначена для Windows x64 и содержит .NET Desktop Runtime.

## Сборка из исходников

Установите .NET SDK 10 и запустите в PowerShell:

```powershell
.\tools\Build.ps1
```

Готовый файл появится как `Виджет лимитов.exe` в корне проекта. Команда для проверок использует только синтетический stdio-сервер и не отправляет запросы генерации:

```powershell
dotnet run --project tests/Widget.Checks -c Release
```
